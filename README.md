DHT11 串口温湿度监视器 - 使用说明
========================================

## 功能说明
这是一个 C# WinForms 应用程序，用于实时监控和显示通过串口发送的 DHT11 温湿度传感器数据。

## 主要功能
1. **串口选择** - 下拉菜单选择可用的串口
2. **波特率设置** - 支持 9600, 19200, 38400, 57600, 115200 等常见波特率
3. **实时数据显示** - 左上显示温度和湿度的当前值
4. **折线图表** - 显示最近 100 个数据点的温湿度趋势
   - 红色线：温度数据
   - 蓝色线：湿度数据

## 使用步骤

### 1. 打开应用程序
   - 编译并运行项目，主窗口会自动显示

### 2. 配置串口参数
   - 从"串口选择"下拉菜单中选择连接设备的串口（如 COM3）
   - 从"波特率"下拉菜单中选择匹配设备的波特率（默认 9600）

### 3. 打开串口
   - 点击"打开串口"按钮
   - 成功打开后，按钮文字变为"关闭串口"

### 4. 查看数据
   - 实时温度和湿度值在窗口上方显示
   - 折线图实时绘制数据趋势

### 5. 关闭串口
   - 点击"关闭串口"按钮停止读取数据

## 数据格式
设备应该发送如下格式的数据（以换行符结尾）：
```
Temp:25.5,Hum:60.3
```

格式说明：
- `Temp:` 后面是温度值（浮点数，单位°C）
- `,` 分隔符
- `Hum:` 后面是湿度值（浮点数，单位%）
- 每行数据末尾必须有换行符 `\n`

## 界面组成
- **顶部区域** - 串口选择、波特率选择、打开/关闭按钮
- **信息区域** - 显示当前温度（红色）和湿度（蓝色）值
- **图表区域** - 显示数据趋势的折线图，包含坐标轴、网格和图例

## 常见问题

### 问题：无法识别串口
**解决方案**：
- 确保设备已连接到电脑
- 检查驱动程序是否正确安装
- 在设备管理器中查看设备的串口号

### 问题：数据显示不正确
**解决方案**：
- 确认波特率设置与设备一致
- 检查数据格式是否为 `Temp:XX.X,Hum:XX.X` 格式
- 确保数据末尾有换行符

### 问题：应用程序崩溃
**解决方案**：
- 检查 .NET Framework 4.7.2 是否已安装
- 查看应用程序日志获取更多信息

## 技术规格
- **开发语言**：C#
- **框架**：.NET Framework 4.7.2
- **界面**：Windows Forms
- **最大记录点数**：100 个
- **支持波特率**：9600, 19200, 38400, 57600, 115200
