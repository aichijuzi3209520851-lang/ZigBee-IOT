# DHT11数据格式测试样例

## 测试方法
你可以在串口助手中发送以下测试数据来测试上位机的解析功能。

## 格式1: Temperature:XX Humidity:XX
```
Temperature:22   Humidity:67
Temperature:25.5 Humidity:60.2
Temperature:18 Humidity:45
Temperature:30 Humidity:80
```

## 格式2: T&H：XX XX
```
T&H：24 84
T&H:25.5 60.2
T&H：18 45
T&H:30 80
```

## 格式3: Temp:XX Hum:XX
```
Temp:22 Hum:67
Temp:25.5 Hum:60.2
Temp:18 Hum:45
Temp:30 Hum:80
```

## 格式4: T:XX H:XX
```
T:22 H:67
T:25.5 H:60.2
T:18 H:45
T:30 H:80
```

## 格式5: XX,XX (温度,湿度)
```
22,67
25.5,60.2
18,45
30,80
```

## 自定义格式示例

### 示例1: 带单位
数据: `温度:25°C 湿度:60%`
- 温度正则: `温度:\s*(\d+\.?\d*)`
- 湿度正则: `湿度:\s*(\d+\.?\d*)`

### 示例2: JSON格式
数据: `{"temp":25.5,"hum":60.2}`
- 温度正则: `"temp":\s*(\d+\.?\d*)`
- 湿度正则: `"hum":\s*(\d+\.?\d*)`

### 示例3: 带方括号
数据: `[Temp:25.5][Hum:60.2]`
- 温度正则: `\[Temp:\s*(\d+\.?\d*)\]`
- 湿度正则: `\[Hum:\s*(\d+\.?\d*)\]`

### 示例4: 斜杠分隔
数据: `25.5/60.2`
- 温度正则: `(\d+\.?\d*)/`
- 湿度正则: `/(\d+\.?\d*)`

### 示例5: 等号格式
数据: `Temp=25.5 Hum=60.2`
- 温度正则: `Temp=\s*(\d+\.?\d*)`
- 湿度正则: `Hum=\s*(\d+\.?\d*)`

## 批量测试脚本

如果你想用串口助手批量测试,可以复制以下数据连续发送:

```
Temperature:22 Humidity:67
Temperature:23 Humidity:68
Temperature:24 Humidity:69
Temperature:25 Humidity:70
Temperature:26 Humidity:71
Temperature:27 Humidity:72
Temperature:28 Humidity:73
Temperature:29 Humidity:74
Temperature:30 Humidity:75
```

## 注意事项

1. 每条数据之间建议加换行符(\r\n或\n)
2. 数据发送间隔建议至少100ms
3. 温度范围: -50°C ~ 100°C
4. 湿度范围: 0% ~ 100%
5. 超出范围的数据会被自动过滤

## 模拟实时数据

你可以使用Arduino或其他单片机发送模拟数据:

```cpp
// Arduino示例代码
void setup() {
  Serial.begin(9600);
}

void loop() {
  float temp = random(200, 300) / 10.0;  // 20.0 ~ 30.0
  float hum = random(400, 800) / 10.0;   // 40.0 ~ 80.0

  // 格式1
  Serial.print("Temperature:");
  Serial.print(temp, 1);
  Serial.print(" Humidity:");
  Serial.println(hum, 1);

  delay(1000);  // 每秒发送一次
}
```
