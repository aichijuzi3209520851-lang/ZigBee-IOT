# DHT11温湿度上位机 - 自定义数据格式功能说明

## 功能概述

本次优化为DHT11温湿度上位机程序添加了**自定义数据格式解析功能**,使程序能够灵活地解析不同厂家、不同格式的温湿度数据,大大提高了程序的通用性和灵活性。

## 主要特性

### 1. 数据格式选择器
- 在控制面板增加了"数据格式"下拉菜单
- 用户可以像选择波特率一样轻松切换数据格式
- 提供多种预设格式,开箱即用

### 2. 预设数据格式(共5种)

#### 格式1: Temperature:XX Humidity:XX
- **示例:** `Temperature:25 Humidity:60`
- **说明:** 这是原始默认格式,适用于大多数DHT11模块

#### 格式2: T&H:XX XX
- **示例:** `T&H:24 84` 或 `T&H:24 84`
- **说明:** 适用于一些简化输出的DHT11模块

#### 格式3: Temp:XX Hum:XX
- **示例:** `Temp:25 Hum:60`
- **说明:** 使用缩写形式的标准格式

#### 格式4: T:XX H:XX
- **示例:** `T:25 H:60`
- **说明:** 极简格式,只用单个字母标识

#### 格式5: XX,XX (温度,湿度)
- **示例:** `25.5,60.2`
- **说明:** 纯数值格式,使用逗号分隔温度和湿度

### 3. 自定义格式功能
- 当选择"自定义格式"时,会启用"自定义"按钮
- 点击按钮打开自定义格式对话框
- 支持使用正则表达式自定义解析规则
- 适用于任何非标准数据格式

## 使用方法

### 基本使用流程

1. **启动程序**
   - 打开DHT11上位机程序

2. **选择数据格式**
   - 在控制面板找到"数据格式"下拉菜单
   - 根据你的DHT11模块发送的数据格式选择对应的预设格式
   - 如果不确定,可以先连接串口,查看右侧接收日志中的数据格式

3. **连接串口**
   - 选择串口和波特率
   - 点击"连接串口"
   - 观察接收日志和数据解析情况

4. **验证解析**
   - 如果左侧温湿度显示正常且折线图更新,说明格式选择正确
   - 如果显示"解析失败",说明需要更换数据格式

### 自定义格式设置

如果预设格式都无法匹配你的数据,可以使用自定义格式:

1. **选择自定义格式**
   - 在数据格式下拉菜单中选择"自定义格式"
   - "自定义"按钮会变为可用状态

2. **打开自定义对话框**
   - 点击"自定义"按钮
   - 弹出自定义格式对话框

3. **输入正则表达式**
   - **温度正则表达式:** 用于匹配温度数值的正则表达式
   - **湿度正则表达式:** 用于匹配湿度数值的正则表达式
   - 正则表达式必须包含至少一个捕获组 `()` 来提取数值

4. **正则表达式示例**

   | 数据格式 | 温度正则表达式 | 湿度正则表达式 |
   |---------|--------------|--------------|
   | `Temp=25 Hum=60` | `Temp=\s*(\d+\.?\d*)` | `Hum=\s*(\d+\.?\d*)` |
   | `温度:25°C 湿度:60%` | `温度:\s*(\d+\.?\d*)` | `湿度:\s*(\d+\.?\d*)` |
   | `[25.5, 60.2]` | `\[\s*(\d+\.?\d*)` | `,\s*(\d+\.?\d*)` |
   | `25.5/60.2` | `(\d+\.?\d*)/` | `/(\d+\.?\d*)` |

5. **测试验证**
   - 点击"确定"保存设置
   - 程序会在接收日志中显示解析结果
   - 观察是否能正确提取温湿度数值

## 正则表达式基础知识

如果你不熟悉正则表达式,以下是常用的语法:

- `\d` - 匹配任意数字 (0-9)
- `\d+` - 匹配一个或多个数字
- `\.` - 匹配小数点
- `?` - 前面的字符可有可无
- `\s` - 匹配空格
- `\s*` - 匹配零个或多个空格
- `()` - 捕获组,用于提取需要的部分
- `[：:]` - 匹配中文冒号或英文冒号

### 常见模式

1. **整数:** `(\d+)`
2. **小数:** `(\d+\.?\d*)`
3. **带符号数:** `([+-]?\d+\.?\d*)`
4. **带空格的数:** `\s*(\d+\.?\d*)`

## 注意事项

1. **数据范围验证**
   - 温度范围: -50°C ~ 100°C
   - 湿度范围: 0% ~ 100%
   - 超出范围的数据会被自动过滤

2. **正则表达式验证**
   - 输入的正则表达式必须是有效的
   - 如果格式错误,程序会提示并拒绝保存

3. **实时切换**
   - 可以在连接串口后动态切换数据格式
   - 无需断开连接即可测试不同格式

4. **日志查看**
   - 右侧接收日志会显示原始数据和解析结果
   - 绿色提示表示解析成功
   - 红色提示表示解析失败

## 技术实现

### 核心技术
- 使用 **C# 正则表达式 (Regex)** 进行数据匹配和提取
- 支持两种解析模式:
  - **分离式:** 温度和湿度使用不同的正则表达式分别匹配
  - **组合式:** 温度和湿度在同一个正则表达式中匹配(如格式2和格式5)

### 数据流程
```
串口数据接收 → 数据缓冲 → 按行分割 → 正则匹配 → 数值提取 → 范围验证 → 显示更新
```

## 常见问题

### Q1: 选择了格式但还是无法解析?
**A:** 请检查:
- 数据格式是否完全匹配(包括大小写、符号)
- 波特率设置是否正确
- 串口连接是否稳定
- 查看接收日志中的原始数据格式

### Q2: 自定义正则表达式如何编写?
**A:**
1. 先在接收日志中复制一条完整的数据
2. 在线使用正则表达式测试工具(如 regex101.com)
3. 编写正则表达式并测试匹配
4. 确保使用捕获组 `()` 提取数值部分

### Q3: 是否支持多个数据源同时解析?
**A:** 当前版本仅支持单个串口单一格式解析,如需多格式混合,建议使用自定义格式编写更复杂的正则表达式。

### Q4: 数据解析失败会影响程序运行吗?
**A:** 不会。解析失败只会在日志中显示提示,不会影响程序的稳定性和其他功能。
